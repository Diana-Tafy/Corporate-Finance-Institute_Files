# Corporate-Finance-Institute
# Corporate Finance Institute (CFI) Portfolio & Practice Repository

Welcome to my repository dedicated to coursework, projects, and practical exercises completed as part of the **Corporate Finance Institute (CFI)** training modules. This repository serves as a centralized collection of data analytics models, dashboards, transformations, and scripts developed using business intelligence tools and programming frameworks.

---

## 📁 Repository Structure

The repository is organized into domain-specific directories matching core analytics competencies:

| Folder | Focus & Contents |
| :--- | :--- |
| **`DATA VISUALS & DASHBOARDS`** | Dashboard design frameworks, visual reporting, and presentation layouts. |
| **`DAX & TIME INTELLIGENCE`** | Power BI Data Analysis Expressions (DAX), measure calculations, YTD/MTD analytics, and custom time intelligence patterns. |
| **`POWER BI`** | Interactive `.pbix` reports, data models, schema setups, and published report assets. |
| **`POWER QUERY`** | ETL workflows, M code scripts, data transformation steps, and cleaning queries. |
| **`PYTHON`** | Exploratory Data Analysis (EDA), regression scripts, Jupyter notebooks (`.ipynb`), and statistical analytics. |
| **`REGRESSION`** | Statistical modelling, simple/multiple linear regression models, Excel Add-in outputs (`RegressIt`), and evaluation metrics. |
| **`SQL`** | Database queries, table joins, data aggregations, and analytical filtering scripts. |
| **`TABLEAU`** | Interactive workbooks (`.twbx`), multi-axis dashboards, and retail/operational performance visualizations. |

---

## 🛠️ Tools & Technologies Used

* **Languages:** Python (Pandas, NumPy, Matplotlib, Statsmodels, Scikit-learn), SQL, DAX, M Code
* **Business Intelligence & Analytics:** Microsoft Power BI, Tableau, Excel (RegressIt, Analysis ToolPak)
* **Environment & Tools:** JupyterLab, Anaconda, VS Code, Git/GitHub
